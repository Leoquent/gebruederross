## 2026-10-09 - Native Lazy Loading & Async Decoding on the Web
**Learning:** Adding `loading="lazy"` and `decoding="async"` to heavy images below the fold is a cheap, natively-supported way to improve time to interactive (TTI) and First Contentful Paint (FCP) without a complex framework overhead on a static site.
**Action:** Always verify if large images below the fold lack these attributes, especially on statically served, custom-built pages.
